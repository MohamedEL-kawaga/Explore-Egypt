# 🇪🇬 Explore Egypt — Travel Website

A responsive travel website designed to showcase the beauty of Egypt, featuring popular destinations, Egyptian culture, traditional cuisine, and travel packages.

## 🌍 Overview

**Explore Egypt** is a static travel landing page built with **HTML, CSS, and JavaScript**.
The project focuses on creating a modern, responsive, and interactive experience for users who want to explore Egypt's most popular destinations and cultural highlights.

## ✨ Features

- 🏠 Modern hero section with navigation bar
- 🗺️ Popular Egyptian destinations
- 🍽️ Traditional Egyptian food section
- 🎒 Travel packages and booking-style sections
- 📱 Fully responsive design for desktop, tablet, and mobile
- ☰ Interactive mobile navigation menu
- 🎨 Modern travel-themed UI
- ⚡ Dynamic destination cards generated using JavaScript
- ✨ Smooth animations and interactive UI elements

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic elements
- **CSS3** — Styling, responsive layouts, animations, and visual effects
- **JavaScript (ES6+)** — Dynamic content and user interactions
- **Font Awesome** — Icons
